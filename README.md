# Reachy Mini × 0G Hackathon

Run-of-show materials for a hackathon where teams build apps for the [Reachy Mini](https://www.pollen-robotics.com/reachy-mini/) robot that integrate with the [0G stack](https://0g.ai/) (Chain, Compute, Storage). One physical Reachy Mini Wireless on site — most teams build in simulation and deploy to the shared robot for demos.

## Documents

- **[hackathon-guide.md](hackathon-guide.md)** — Attendee setup: sim install, first script, app publishing, deployment.
- **[demo-station.md](demo-station.md)** — Operator card for whoever runs the robot during demos: queue, stop/reset, fixes.
- **[judging-rubric.md](judging-rubric.md)** — Fast 0G-centered scoring sheet (out of 25).
- **[project-inspiration.md](project-inspiration.md)** — 1–2 day project ideas, grouped by 0G service.

For AI coding agents working on these docs, see [AGENTS.md](AGENTS.md).
